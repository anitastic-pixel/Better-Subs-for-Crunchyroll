1 The big picture

Crunchyroll decides which subtitles you get and how they look. Better Subs sits between the page and the player: it reads the same episode data the player receives, fetches the subtitle files itself, and draws them in its own layer on top of the video.

Crunchyrollepisode data + subtitle files
→
Better Subsreads, fetches, restyles
→
your screen ← typeset sign Our subtitle overlay — styled your way Every language in the catalog Perfectly timed to your video

Nothing is modified on Crunchyroll's servers and no video is touched — the extension only changes what your own browser displays.

3 Where the subtitles come from

Every episode ships a catalog of subtitle files in many languages — including some the player never offers you. When an episode loads, the extension builds that catalog and the ▾ menu lists everything it found. Picking a language fetches the real subtitle file and renders it directly.

The Japanese-audio version of an episode usually carries the most complete subtitle set, so the extension quietly checks it too and offers the best file for each language. On dubs, the dub's own closed captions show up marked (CC).

4 Two layers: dialogue and signs

A subtitle file contains two kinds of lines: dialogue (what's spoken, drawn as the bottom band) and typeset signs (translated on-screen text — shop names, phone screens, notes — positioned where the original text is). They're separate layers — try the toggles, exactly like ▾ → Show on screen:

Show on screen
駅 → Station I'm heading home.
Both layers on — spoken lines at the bottom, translated signs where the original text sits. These are the same rows you'll find in the popup and in ▾ → Show on screen.
Dialogue off — the bottom band is gone, but signs keep rendering. Nice for testing your listening while still catching on-screen text.
Typeset signs off — only spoken lines show; on-screen text stays untranslated.
Everything off — the overlay stays active but draws nothing. Flip either switch to bring a layer back (the JP CC button still shows as active).

Signs keep their original fonts, rotation and placement — they're drawn by a real subtitle engine (libass), the same one fansub players use.

5 Hiding Crunchyroll's own subtitles

So you don't see two sets of subtitles at once, the extension hides Crunchyroll's. Soft subtitles (text drawn over the video) are hidden instantly. But Crunchyroll's newer player often burns subtitles into the video itself ("hardsubs") — those can't be hidden, only avoided, by asking the player for the clean, text-free stream. This is the exact toggle from the popup — try it:

Show on screen
what you see ✓ clean stream (after reload) Burned-in text — part of the picture Our overlay
Toggle ON (the default) — Crunchyroll's subtitles stay. On a hardsub stream that means two subtitle sets at once: the italic line is baked into the video pixels and our overlay draws on top of it. If you've ever thought "I can still see Crunchyroll's subtitles underneath" — this toggle is why.
Toggle OFF — the extension asks for the clean, text-free video stream. Takes effect on the next video load, so expect a reload prompt if a burned stream is already playing. This same switch lives in the popup and in ▾ → Show on screen.

Because the burned-in text is part of the video, switching to the clean stream takes effect when the video next loads — that's why a reload prompt appears if a burned stream is already playing when you hide Crunchyroll's subtitles.

6 Dual subtitles & Learning mode

Show two languages at once: a primary band, and a secondary band above it (▾ → Second subtitle). Learning mode is the guided version — one tap sets the primary to match the audio you're hearing and puts your own language underneath. There's no audio switch to press in the extension — pick which version you'd be watching, and see how the bands follow:

learning mode I'm heading home.もう家に帰るね。 もう家に帰るね。I'm heading home. (CC)
Japanese audio — the primary band shows Japanese (read what you hear), your language sits above for support. Real thing: ▾ → 📚 Match my audio.
English dub — the primary flips to the dub's own closed captions, marked (CC), which match the spoken script word-for-word; the support band becomes Japanese. Same button — learning mode always follows the audio track you're on.

Study helpers pair with this: Alt+R replays the current line, Alt+C copies it (for a dictionary or flashcards), and auto-pause stops playback at the end of each line so you can read at your own pace.

7 How subtitles stay in sync

A subtitle file is timed for one specific cut of an episode — a dub can run on a slightly different cut, so a borrowed file would drift. The extension re-times it: lines with matching text in both versions become anchors, and everything between them is shifted to fit. This happens automatically — there's no button for it in the extension — but you can watch what it does:

subtitle file

Before — the file was timed for a different cut, so every line lands early. This is what an unsynced borrowed subtitle looks like.
After — the orange anchor lines matched, and everything slid into place. In the player this happens automatically; a badge near the button tells you it synced (or that it used the approximate fallback).

When the two versions are too different to anchor precisely, a coarse fallback estimates a single overall shift and tells you it's approximate. And you can always nudge by hand: ▾ → Adjust timing moves subtitle 1, subtitle 2, or both, in 0.1s steps, remembered per episode.
