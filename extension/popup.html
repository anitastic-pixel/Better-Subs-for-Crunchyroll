Machine translation
Fill in a language Crunchyroll doesn't carry — e.g. Japanese — by machine-translating an existing track. Bring your own DeepL API key (the free tier covers ~500k characters/month). It's stored only on this device and sent only to DeepL. Machine output is an approximation, not authored subtitles.
