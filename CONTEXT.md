# Better Subs for Crunchyroll

A Chrome extension that replaces Crunchyroll's per-locale subtitle tracks with the user's choice of locale, regardless of which audio dub is playing. Renders subtitles via a custom ASS overlay and works around server-side data errors (wrong subtitle file linked to a locale).

## Language

**Episode**:
A single Crunchyroll episode the user is currently viewing. Identified by the guid in the `/watch/<guid>` URL. The in-memory data structure that holds everything tied to one viewing — subtitle URLs, parsed cues, JP-mapping, validation results, the catalog instance, auth headers — is also called the **Episode**.
_Avoid_: Session, video, watch.

**Audio session**:
A Crunchyroll streaming session bound to one audio-dub locale. Each session exposes its own subtitle URL matrix on the playback API. An **Episode** typically has multiple **Audio sessions** (one per available dub).
_Avoid_: Audio track, dub session.

**Source**:
The subtitle locale the user has chosen to display. May be the same as or different from the audio dub. Persisted across episodes as a user preference.
_Avoid_: Subtitle track, sub language.

**Custom source**:
A non-Crunchyroll subtitle track attached to one **Episode** — either an uploaded file (`kind:'local'`) or a machine translation (`kind:'mt'`, generated by translating an existing CR track via the user's DeepL/Google key). Lives in the **Episode**'s custom-source registry (serializable records keyed by an id like `custom:local`), shows in the **Source** picker's "Custom" section, and rides the same apply path as a CR locale — `interceptor.js` branches on `isCustomId(activeSource)` and feeds the record's cues straight to the renderer, skipping the URL fetch and wrong-title probe. Its `sync` params (`none` | `linear` two-point | `anchors` auto) are applied at display time. Unlike a **Source**, a custom source is per-**Episode** (keyed by guid) and is not written to the cross-episode preference. The **Episode** only stores and serves records; identity (`isCustomId`, the `custom:local` id) and record construction live in `lib/custom-source.js`, and the `sync` timing model — deriving a `linear` map from two marks, and baking any sync onto a **Cue** array — lives in `lib/sub-sync.js` (the `anchors` mode delegates to **Remaster**).
_Avoid_: External sub, imported track.

**Secondary subtitle**:
A second **Source** shown *alongside* the primary (dual subtitles) — e.g. a target language plus the viewer's own. May be a CR locale OR a **Custom source** (an MT track / upload). Chosen from the **Source** picker's "Second subtitle" submenu and persisted as a cross-episode preference (`crSubFix_secondary`). Its **Cues** go into a parallel slot (`episode.secondaryCues`, read via `secondaryCuesAt`) — fetched for a CR locale, or read straight from the registry for a **Custom source** — and rendered by `cue-renderer.js` as a bottom-centred band stacked just above the primary dialogue. It rides the SAME timeline as the primary (both pulled from the JP **Audio session** row), so no **Remaster** is needed. By default only its dialogue is shown, but a **Signs** selector (`crSubFix_signsrc`: `primary` | `secondary` | `both`) chooses which track draws the typeset **Signs** — `both` merges the two sign layers via `signTrack.mergeSigns` (same-`\pos` signs overlap). A secondary equal to the active **Source** is dropped (no duplicate band).
_Avoid_: Second track, dual track (use **Secondary subtitle**).

**Catalog**:
Per-**Episode** registry of subtitle URLs (indexed by `(audio session, subtitle locale)`) and per-locale validation status. Owns the policy for picking the best URL for a given **Source** and the monotonic rule for validation transitions. Lives in `lib/subtitle-catalog.js` and is held by the **Episode**, which wires it to localStorage at construction.
_Avoid_: Index, registry.

**Cue**:
One subtitle line with start/end times and styled text spans. Output of the parser; input to the renderer.

**Sign**:
A positioned typeset **Cue** — a `\pos`/`\move` line in an ASS file that places on-screen text (a location card, a UI caption, a translated sign) rather than bottom-anchored dialogue. Signs are rendered by real libass (SubtitlesOctopus in `content.js`), including any fonts the ASS embeds, so the 3-D typeset matches Crunchyroll's own burned-in render; dialogue stays on the extension's CSS overlay. The *typeset-signs projection* of an ASS file — the subset libass needs (`[Script Info]`/`[V4+ Styles]`/`[Fonts]` plus only the sign lines) — and the machine-translation round-trip over sign text live in `lib/sign-track.js`.
_Avoid_: Typeset, caption, on-screen text (use **Sign** for the line, *typeset* only as an adjective).

**Remaster**:
Reprocessing of **Cues** to align them onto a different **Audio session**'s timeline (used when the chosen **Source** comes from a different session than the active dub). Anchor-matched, piecewise-linear time mapping.

**Wrong-title**:
A **Source** whose subtitle file on Crunchyroll's CDN was authored for a completely different title. Detected by comparing subtitle end time against video duration. The **Catalog**'s validation map records affected sources so the menu can flag them.

**Native track**:
Crunchyroll's own subtitle rendering — the captions it draws through its player, independent of the browser's TextTrack API. While a **Source** overlay is active, the extension *suppresses* the **Native track** (disabling text tracks, injecting hiding CSS, and re-applying on a poll) so only the chosen **Source**'s **Cues** are visible. Suppression policy lives in `lib/sub-suppression.js`.
_Avoid_: Native subs, CC layer.

## Relationships

- An **Episode** has one **Catalog**.
- An **Episode** has many **Audio sessions** (discovered as playback responses arrive).
- A **Catalog** maps `(Audio session, Source)` to a subtitle URL.
- A **Source** lives at the user level (preference) but is resolved per-**Episode** via the **Catalog**.
- A **Cue** belongs to a **Source** + **Audio session** pair; **Remaster** transforms cues from one **Audio session**'s timeline to another's.

## Example dialogue

> **Dev:** "When the user changes **Source** mid-playback, do we always need to **Remaster**?"
> **Domain expert:** "Only if the chosen **Source** lives in an **Audio session** other than the one currently playing. If the **Source** locale matches the active dub's session, the **Cues** are already on the right timeline."

## Flagged ambiguities

- "Session" historically meant both "**Audio session**" and informally "current viewing." Resolved: **Episode** for the viewing, **Audio session** for the Crunchyroll streaming concept. The word "session" alone is reserved for **Audio session**.
